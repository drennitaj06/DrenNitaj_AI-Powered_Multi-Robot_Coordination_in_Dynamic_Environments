# MARL add-on lock (Issue #5). Layers on top of requirements-lock.txt, so the base lock stays light.
# Install: pip install -r requirements-lock-marl.txt -e ".[marl]"
# Versions verified on Windows 11 / Python 3.14.3 (CPU build, no CUDA).
# The CPU index below is required on Linux (PyPI's Linux wheel depends on the CUDA packages) and
# selects the identical CPU wheel on Windows. It applies to the whole pip invocation, so the
# "-e .[marl]" part resolves torch to the pinned 2.15.0+cpu already requested here, never to a
# second, different build. The "marl" extra in pyproject.toml pins "torch==2.15.0", which the
# local build tag +cpu satisfies (PEP 440).
--extra-index-url https://download.pytorch.org/whl/cpu
-r requirements-lock.txt
torch==2.15.0+cpu
filelock==4.2.12
fsspec==2026.9.0
